## Decisions made during implementation

- **Benchmarks use index-fund proxies** (NAV of a low-cost index fund per index, via mfapi), stored as `index_fund_proxy`. Real TRI from niftyindices.com is deferred to v2 (it needs browser-like requests). Some proxies are young (Nifty 500 proxy under 2 years), so 3Y/5Y benchmark-relative metrics are often n/a: precompute must store null, not crash.
- **Runs locally with no cloud accounts**: `DATABASE_URL=pglite:<dir>` (or `pglite:memory` in tests) and `NAV_STORE=fs:<dir>`; data goes in `.data/` (gitignored). Supabase and R2 plug in through env vars later (see `.env.example`). Never read `.env`.
- Metric results are typed `MetricResult<T>` (`ok` / `na` with a reason), never NaN.
- Cache Components / PPR is off in `next.config.ts`. shadcn uses the base-nova style (no `asChild`; use `render={...}`).
- `typecheck` runs `next typegen` first.

## Working rules (from the owner)

- npm: always install from the official registry: `npm install --registry=https://registry.npmjs.org/` (the global npmrc points at an unreachable internal mirror). Global `ignore-scripts=true`: use `npm rebuild <pkg>` where a package needs install scripts.
- Never use the em dash character. No `lint --fix` / `prettier --write` over the whole tree.
- Local commits are fine; never push. No AI co-author trailers.
- Definition of done per ticket: `npm run typecheck && npm run lint && npm test && npm run build` pass. When a ticket is done, set its `Status:` to `resolved`.
- Tests are welcome for the math and parsers; for UI work keep tests light and check the page in a browser (light and dark, desktop and narrow).
